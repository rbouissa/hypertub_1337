═══════════════════════════════════════════════════════════════════════
2. DATABASE SETUP
═══════════════════════════════════════════════════════════════════════

# Create database migrations
python manage.py makemigrations
python manage.py makemigrations movies

# Apply migrations (create tables)
python manage.py migrate

# Create admin user (username: admin, password: admin)
python manage.py shell -c "from django.contrib.auth import get_user_model; User = get_user_model(); User.objects.filter(username='admin').delete(); User.objects.create_superuser('admin', 'admin@example.com', 'admin'); print('Admin created successfully')"


═══════════════════════════════════════════════════════════════════════
3. POPULATE DATABASE WITH MOVIES
═══════════════════════════════════════════════════════════════════════

# Fetch 20 movies from Archive.org with OMDb ratings
python manage.py populate_movies --limit 20

# For more movies (optional)
python manage.py populate_movies --limit 50

# Skip existing movies
python manage.py populate_movies --limit 20 --skip-existing


═══════════════════════════════════════════════════════════════════════
4. RUN DEVELOPMENT SERVER
═══════════════════════════════════════════════════════════════════════

# Start server on default port (8000)
python manage.py runserver

# Start on specific port
python manage.py runserver 8000

# Allow external access
python manage.py runserver 0.0.0.0:8000

7. TEST ENDPOINTS (CURL Commands)
═══════════════════════════════════════════════════════════════════════

# Get all movies
curl http://localhost:8000/movies/

# Get movie details
curl http://localhost:8000/movies/7/

# Get all comments
curl http://localhost:8000/comments/

# Create a comment
curl -X POST http://localhost:8000/movies/7/comments/ \
  -H "Content-Type: application/json" \
  -d '{"comment": "Great movie!", "username": "testuser"}'

# Update a comment
curl -X PATCH http://localhost:8000/comments/1/ \
  -H "Content-Type: application/json" \
  -d '{"comment": "Updated!", "username": "testuser"}'

# Delete a comment
curl -X DELETE http://localhost:8000/comments/1/

# Stream video (download test)
curl http://localhost:8000/movies/7/stream/ --output test.mp4

12. TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

Problem: Port already in use
Solution: python manage.py runserver 8001

Problem: OMDb API not working
Solution: export OMDB_API_KEY='16e87ea8'

Problem: No movies in database
Solution: python manage.py populate_movies --limit 20

Problem: Admin login not working
Solution: Recreate admin user with shell command above

Problem: Database locked
Solution: Close all connections and restart server
