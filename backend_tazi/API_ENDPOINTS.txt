================================================================================
                        API ENDPOINTS DOCUMENTATION
================================================================================

BASE URL: http://localhost:8000

================================================================================
MOVIE ENDPOINTS
================================================================================

1. LIST ALL MOVIES
   Method: GET
   Path: /movies/
   
   Example:
   curl http://localhost:8000/movies/
   
   Response:
   [
     {"id": 1, "name": "Movie Title"},
     {"id": 2, "name": "Another Movie"}
   ]

--------------------------------------------------------------------------------

2. SEARCH MOVIES
   Method: GET
   Path: /movies/search/?q=<query>
   
   Example:
   curl "http://localhost:8000/movies/search/?q=friday"
   curl "http://localhost:8000/movies/search/?q=girl"
   
   Response:
   {
     "query": "friday",
     "count": 1,
     "results": [
       {
         "id": 1,
         "name": "His Girl Friday",
         "archive_identifier": "His_Girl_Friday",
         "imdb_id": "tt0032599",
         "imdb_rating": 8.0,
         "production_year": 1940,
         "length": 92
       }
     ]
   }

--------------------------------------------------------------------------------

3. GET MOVIE DETAILS
   Method: GET
   Path: /movies/<id>/
   
   Example:
   curl http://localhost:8000/movies/1/
   
   Response:
   {
     "id": 1,
     "name": "His Girl Friday",
     "archive_identifier": "His_Girl_Friday",
     "imdb_id": "tt0032599",
     "imdb_rating": 8.0,
     "img_url": "https://m.media-amazon.com/images/...",
     "genre": "Comedy, Drama, Romance",
     "production_year": 1940,
     "length": 92,
     "video_url": "https://archive.org/...",
     "available_subtitles": ["English", "Arabic"],
     "number_of_comments": 5
   }

--------------------------------------------------------------------------------

4. CREATE MOVIE
   Method: POST
   Path: /movies/create/
   
   Example:
   curl -X POST http://localhost:8000/movies/create/ \
     -H "Content-Type: application/json" \
     -d '{
       "name": "New Movie",
       "archive_identifier": "new_movie_2024",
       "imdb_id": "tt1234567",
       "imdb_rating": 7.5,
       "img_url": "https://m.media-amazon.com/images/...",
       "genre": "Action, Thriller",
       "production_year": 2024,
       "length": 120,
       "video_url": "https://archive.org/download/..."
     }'
   
   Response:
   {
     "id": 51,
     "name": "New Movie",
     "archive_identifier": "new_movie_2024",
     "message": "Movie created successfully"
   }

--------------------------------------------------------------------------------

5. UPDATE MOVIE
   Method: PUT or PATCH
   Path: /movies/<id>/update/
   
   Example:
   curl -X PUT http://localhost:8000/movies/1/update/ \
     -H "Content-Type: application/json" \
     -d '{
       "name": "Updated Movie Title",
       "imdb_rating": 8.5,
       "genre": "Drama, Romance"
     }'
   
   Response:
   {
     "id": 1,
     "name": "Updated Movie Title",
     "message": "Movie updated successfully"
   }

--------------------------------------------------------------------------------

6. DELETE MOVIE
   Method: DELETE
   Path: /movies/<id>/delete/
   
   Example:
   curl -X DELETE http://localhost:8000/movies/1/delete/
   
   Response:
   {
     "message": "Movie \"His Girl Friday\" deleted successfully"
   }

--------------------------------------------------------------------------------

7. STREAM VIDEO
   Method: GET
   Path: /movies/<id>/stream/
   
   Example:
   curl http://localhost:8000/movies/1/stream/
   
   # With range header for partial content
   curl -H "Range: bytes=0-1023" http://localhost:8000/movies/1/stream/


================================================================================
COMMENT ENDPOINTS
================================================================================

8. LIST ALL COMMENTS
   Method: GET
   Path: /comments/
   
   Example:
   curl http://localhost:8000/comments/
   
   Response:
   [
     {
       "id": 1,
       "author_username": "user1",
       "date": "2026-01-14T12:00:00Z",
       "content": "Great movie!",
       "movie_id": 5,
       "movie_name": "His Girl Friday"
     }
   ]

--------------------------------------------------------------------------------

6. GET COMMENT DETAILS
   Method: GET
   Path: /comments/<id>/
   
   Example:
   curl http://localhost:8000/comments/1/
   
   Response:
   {
     "id": 1,
     "comment_id": 1,
     "author_username": "user1",
     "date": "2026-01-14T12:00:00Z",
     "content": "Great movie!",
     "movie_id": 5,
     "movie_name": "His Girl Friday"
   }

--------------------------------------------------------------------------------

7. CREATE COMMENT
   Method: POST
   Path: /movies/<movie_id>/comments/
   
   Example:
   curl -X POST http://localhost:8000/movies/1/comments/ \
     -H "Content-Type: application/json" \
     -d '{"comment": "Amazing classic film!", "username": "john_doe"}'
   
   Request Body:
   {
     "comment": "Amazing classic film!",
     "username": "john_doe"
   }
   
   Response:
   {
     "id": 2,
     "author_username": "john_doe",
     "date": "2026-01-15T10:30:00Z",
     "content": "Amazing classic film!",
     "movie_id": 1,
     "message": "Comment created successfully"
   }

--------------------------------------------------------------------------------

8. UPDATE COMMENT
   Method: PATCH
   Path: /comments/<id>/
   
   Example:
   curl -X PATCH http://localhost:8000/comments/1/ \
     -H "Content-Type: application/json" \
     -d '{"comment": "Updated comment text", "username": "john_doe"}'
   
   Request Body:
   {
     "comment": "Updated comment text",
     "username": "john_doe"
   }
   
   Response:
   {
     "id": 1,
     "content": "Updated comment text",
     "author_username": "john_doe",
     "date": "2026-01-14T12:00:00Z",
     "message": "Comment updated successfully"
   }

--------------------------------------------------------------------------------

9. DELETE COMMENT
   Method: DELETE
   Path: /comments/<id>/
   
   Example:
   curl -X DELETE http://localhost:8000/comments/1/
   
   Response:
   {
     "message": "Comment deleted successfully",
     "id": 1
   }


================================================================================
SUBTITLE ENDPOINTS
================================================================================

10. ADD SUBTITLE TO MOVIE
   Method: POST
   Path: /movies/<movie_id>/subtitles/
   
   Example:
   curl -X POST http://localhost:8000/movies/1/subtitles/ \
     -H "Content-Type: application/json" \
     -d '{"language": "French"}'
   
   Request Body:
   {
     "language": "French"
   }
   
   Response:
   {
     "id": 3,
     "movie_id": 1,
     "movie_name": "His Girl Friday",
     "language": "French",
     "created_at": "2026-01-15T10:30:00Z"
   }

--------------------------------------------------------------------------------

11. AUTO-FETCH SUBTITLES FROM ARCHIVE.ORG
    Method: POST
    Path: /movies/<movie_id>/subtitles/auto-fetch/
    
    Example:
    curl -X POST http://localhost:8000/movies/1/subtitles/auto-fetch/
    
    Response:
    {
      "movie_id": 1,
      "movie_name": "His Girl Friday",
      "archive_identifier": "His_Girl_Friday",
      "subtitles_found": 2,
      "subtitles": [
        {
          "id": 1,
          "language": "English",
          "url": "https://archive.org/...",
          "format": "srt",
          "status": "created"
        },
        {
          "id": 2,
          "language": "العربية",
          "url": "https://archive.org/...",
          "format": "vtt",
          "status": "already_exists"
        }
      ]
    }

NOTES
================================================================================

- All endpoints are CSRF exempt for testing purposes
- Comments are created with auto-generated users if username doesn't exist
- Video streaming supports range requests for partial content delivery
- Auto-fetch subtitles only works for movies with valid archive_identifier
- Server must be running: python manage.py runserver
